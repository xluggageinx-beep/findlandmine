# 지뢰찾기 05H · Three Worlds

GitHub Pages 배포용 버전. `index.html`, `audio/` 폴더와 `README.md`를 저장소 최상위에 업로드하세요.

## 조작
- PC 왼쪽 클릭: 칸 열기 / 오른쪽 클릭 또는 F: 깃발
- 모바일 짧게 터치: 칸 열기 / 길게 누르기: 깃발
- 상단 스피커 아이콘: 배경음악 켜기·음소거 / VOL: 음량
- 테마 변경: 2초 크로스페이드
- 상단 `?`: 전체 게임 안내

## 참고
웹 브라우저 자동 재생 정책 때문에 처음에는 무음으로 시작하며, 사용자가 스피커 아이콘을 눌러야 음악이 시작됩니다.
